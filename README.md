# Shepherd Systems — Marketing Website

Static marketing website for Shepherd, a defense and ag-tech company building the Argus System.

## File Structure

```
/
├── index.html      — Home: hero, Argus overview, product cards, use cases
├── about.html      — Company story, mission, values, founder
├── products.html   — Argus System, Hub, and Scout full specifications
├── contact.html    — Contact form and direct contact panel
├── styles.css      — All styles (single file, CSS variables + media queries)
├── script.js       — Parallax, sticky nav, mobile menu, form feedback
└── README.md
```

## Running

Open `index.html` directly in any modern browser. No server, build tools, or dependencies required.

## Stack

- Plain HTML5, CSS3, vanilla JavaScript (ES5-compatible)
- Google Fonts: Rajdhani (headings) + Inter (body)
- Images: Unsplash direct CDN URLs
- No npm, no frameworks, no build step
