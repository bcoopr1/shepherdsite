# Shepherd

Marketing site for Shepherd — a defense and ag-tech company. Flagship product: the **Argus System**, a self-contained LoRa mesh monitoring platform built from two hardware units, the **Hub** and the **Scout**.

## File structure

```
/
├── index.html       Home — hero, parallax intro to Argus, Hub, Scout, and use cases
├── about.html       Company story, mission, founder, tech philosophy
├── products.html    Argus System, Hub, and Scout with specs and features
├── contact.html     Contact form (no backend)
├── styles.css       All styles — global, layout, components, responsive
├── script.js        Parallax, sticky nav scroll state, reveal-on-scroll
└── README.md
```

## Running locally

No build step. No dependencies. Open `index.html` by double-clicking it, or serve the folder with any static server.

## Stack

- Plain HTML, CSS, vanilla JS
- Google Fonts via `<link>` (Rajdhani for display, Inter for body)
- Placeholder imagery from Unsplash via direct URL

## Design

Dark, defense-tech aesthetic. Near-black background, gunmetal surfaces, tactical green accent. Industrial condensed display type, clean sans-serif body.
