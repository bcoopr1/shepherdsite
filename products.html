The Argus System

Persistent awareness, deployed in an afternoon.

Argus is Shepherd’s flagship monitoring platform. It consists of one or more Hubs coordinating a mesh of Scouts over long-range LoRa radio. The system forms itself, heals itself, and requires no cellular, Wi-Fi, or satellite connectivity to operate.

Topology

Self-Forming Mesh

Scouts discover neighbors automatically. The mesh routes around failures, extends with every added node, and converges in seconds.

Range

10+ km Per Hop

Line-of-sight hops exceed 10 km under standard conditions. Multi-hop mesh extends total reach across thousands of acres.

Power

Solar Native

Every Scout is solar-fed with a sealed LiFePO₄ buffer rated for multi-year unattended operation.

Sovereignty

No Cloud Required

All data lives on the Hub. View, query, and export from a local web interface. Backhaul is optional, never assumed.

Security

End-to-End Encrypted

AES-256 on the radio layer. Signed firmware. Device identity pinned at provisioning.

Interface

Phone, Tablet, Terminal

Responsive web UI served locally by the Hub. Works on any browser. No app required, no account to create.

Argus · Hub

The command node.

The Hub is the central coordinator for the Argus mesh. It aggregates telemetry from every Scout on the network, stores it on internal flash, and serves a local web UI for live monitoring, alerting, and historical review.

Powered by 12–24 VDC or solar with battery backup. IP65 enclosure for outdoor mounting. Optional backhaul modules for Wi-Fi, Ethernet, cellular, or satellite when remote access is desired — always off by default.

Argus · Scout

The remote sensor node.

Scouts are the distributed eyes of the Argus mesh. Each unit is a fully sealed, solar-fed sensor node designed to live outdoors through multiple seasons without intervention.

A single Scout carries motion, temperature, magnetic, and tamper sensors, plus configurable external I/O for gate reeds, float switches, trail cams, or custom integrations. Scouts relay for each other, so the mesh gains range every time you add one.
