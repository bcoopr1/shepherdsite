System Overview

Argus — Full Platform

Argus is a self-contained LoRa mesh surveillance and monitoring system. It requires no internet, no cloud subscription, and no external infrastructure of any kind. Deploy it. Walk away. It works.

Architecture note — Argus uses a true mesh topology where each Scout acts as both an endpoint and a relay. Loss of any single node does not break the network. The system self-heals, re-routes, and continues operating.

Hub — Central Base Station

Command. Collect. Control.

The Hub is the nerve center of every Argus deployment. It manages the full mesh network, aggregates telemetry from all Scout nodes, and presents a real-time local dashboard accessible from any device on the same LAN — no internet required.

  • LoRa 915MHz transceiver with high-gain directional antenna
  • Local web dashboard — Wi-Fi AP + Ethernet, zero cloud dependency
  • SD card storage with optional M.2 NVMe for long-term logging
  • Battery-backed with solar charge controller input
  • Supports up to 50 Scout nodes per Hub
  • Configurable alert system: audio, LED, and local push notification
  • Full mesh traffic encrypted — AES-256 end-to-end
  • RadioLoRa 915MHz, 27 dBm output
  • Range15+ mi line-of-sight
  • NetworkSelf-healing mesh, up to 50 nodes
  • Power Input12V DC, solar-compatible, 10Ah backup
  • ConnectivityLocal Wi-Fi AP + Ethernet LAN
  • StorageMicroSD + optional M.2 NVMe
  • Ingress RatingIP65
  • Operating Temp-20°C to +60°C
  • Dimensions220 × 160 × 80 mm
Scout — Remote Sensor Node

Deployed. Autonomous. Invisible.

Scouts are field-hardened sensor nodes designed for unattended, long-duration deployment in any environment. Each one joins the mesh automatically on power-up. No configuration. No registration. No overhead.

  • PIR motion detection with configurable sensitivity zones
  • Environmental sensors: temperature, humidity, barometric pressure
  • GPS module for real-time positional telemetry
  • LoRa mesh relay capability — every Scout extends network range
  • 72+ hour battery life on a single charge; solar supported
  • Magnetic mount + ground stake mount included in kit
  • Tamper detection with immediate Hub alert
  • RadioLoRa 915MHz, 20 dBm output
  • SensorsPIR, Temp/Humidity, Barometric, GPS
  • Battery10Ah LiPo, 72hr+ runtime
  • ChargingUSB-C + 5W solar panel input
  • Mesh RoleEndpoint + automatic relay node
  • Ingress RatingIP67
  • Operating Temp-30°C to +70°C
  • Weight340g including battery
  • Dimensions110 × 70 × 45 mm
